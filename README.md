# SF2e Anachronism 中文汉化

基于用户提供的 SF2 译名表与 [SF2 中文 Wiki](https://sf2.huijiwiki.com/) 制作的独立 Babele 中文补丁，适用于 Foundry VTT 14、PF2e 8.6.0+、Babele 2.9.1+ 和 **SF2e Anachronism 2.4.0 或更新版本**。

在 Foundry 的“安装模组”窗口填入下列清单地址：

```text
https://raw.githubusercontent.com/TenteiGengetsu/anachronism-cn/main/module.json
```

在世界中启用 Babele、SF2e Anachronism 与本中文补丁，并使用简体中文界面。也可下载 [安装包](https://raw.githubusercontent.com/TenteiGengetsu/anachronism-cn/main/dist/anachronism-cn.zip)，解压到 `Data/modules/sf2e-anachronism-zh-cn/`；该目录下应直接包含 `module.json`。

本版为29个导出文件提供翻译文件。0.3.4为全模组汉化的阶段更新：补齐8个职业、157个日志页面（其中150页有正文），扩展动作、族裔、背景、效果等内容，并完成六个怪物／预设角色包共416个角色的本轮复核。异星核心怪物、标志角色和Paizo预设角色三个包仍在审校；额外界面字段的显示层尚未发布。本版并非全模组汉化完结。详见[阶段进度](reports/progress-0.3.4.json)与[覆盖统计](coverage.json)。

译名表优先。Wiki 读取日期为 2026-10-23，读取主命名空间 5,017 页及 Data 命名空间 3,702 页，包含模板字段与嵌套能力。本机 Huiji 客户端在本次读取进程中使用 `sf2` 前缀；未修改全局 MCP 配置。此前仓库中的五个翻译文件在确认源压缩包及译名表哈希一致后复用，基线提交为 `8db9a45a72ec5da605491c38256ca0fb76f6f90f`。

本补丁通过 Babele 提供中文显示，并包含下述用户明确授权的单项规则修正。内嵌物品与日志页面通过 ID 和预期原文匹配，改变过的描述不会被覆盖。除商用型圣洁模组对邪秽目标的骰数3→2外，UUID、骰式、规则元素、ID、数值字段和图片路径保持原值。汉化注册不再锁定原模组版本；最低版本由清单限制为2.4.0。商用型圣洁模组数值修正仍仅适用于2.4.0，并核对源说明与完整规则。

[校验结果](reports/validation.json) 包括 Babele 2.9.1 原生条目匹配、字段映射、完整目标比较、输入不变和过期文本保护。用户已确认 Foundry VTT 14 实测可用；本次由代理执行离线回归验证，具体实测构建号与场景未单独记录。审校记录压缩包位于 `reports/localization-audit.zip`，包含每个改动字段的来源定位、Wiki 修订号、已确认冲突及待译字段清单。未将模组数据视为官方出版物；当前来源政策及已授权修正见下方0.3.2说明。


## 0.2.1 加载修复

修复中文语言代码 cn.foundry_chn 未注册导致 Babele 找不到译文的问题，并支持当前中文语言扩展的完整代码。源模组未启用或版本不匹配时会向 GM 显示提示。

通过 GitHub 清单安装的用户：上传此包中的仓库文件时，必须同时覆盖根目录 module.json、scripts/register.mjs 和 dist/anachronism-cn.zip；随后在 Foundry 更新本汉化至 0.2.1，重新进入世界。请同时启用本汉化、Babele 2.9.1 或更新版和 Anachronism 2.4.0，并选择中文界面。译文用于合集中加载的文档；已导入世界的旧副本需另行更新。

## 0.2.2 初始化修复

根据实际控制台日志修复：Babele 初始化早于 Foundry 核心语言设置的注册，0.2.1 在此时读取 core.language 会抛出异常，导致未注册译文。现于初始化阶段直接注册已知中文语言代码，扩展语言代码在 setup 阶段按 game.i18n.lang 补充，彻底移除汉化代码对 core.language 设置的访问；注册异常与未收到初始化事件分别显示提示。

通过清单安装的用户仍须将本版根目录 module.json、scripts/register.mjs 及 dist/anachronism-cn.zip 一并更新到仓库，然后在 Foundry 更新至 0.2.2 并重新进入世界。


## 0.2.3 动作续补与字段纠正

沿用 0.2.2 的 29 个翻译文件、加载脚本、注册语言代码及目录结构。本批只修改动作翻译文件；其余 28 个文件与加载脚本逐字节不变。

动作中文名称从 68/151 增至 89/151；含中文说明的动作从 49/151 增至 85/151。新增内容包括使节指令、科技法师与机械师动作、嵌套在族裔／变体专长中的反应动作，以及伤害、模板与检定的中文对齐。部分条目只有名称或部分段落已汉化。

纠正初学者幸运、重导能量等嵌套动作的触发／效果错位。对持续时间、技能动作、目标限制、邻接条件等与原条目不同的 Wiki 中文保留英文，并记录在 reports/review-conflicts.json 中；未用新译补齐缺失来源。原有数字字段、规则元素、UUID、宏参数与 HTML 标签保持原值。

安装或更新时保持现有路径：清单 module.json 与安装包 dist/anachronism-cn.zip 均已同步为 0.2.3。完整校验结果见 reports/validation.json；未在运行中的 Foundry 世界实测。

新增 40 条复核记录：Wiki 与原文在目标条件、动作数、持续时间、伤害、字符上限等方面有差异时保留英文。缺失来源的文本未自行补译。

## 0.3.0 法术、装备与全部专长完整汉化

以Babele原导出和Anachronism 2.4.0英文为依据，补齐231个法术、1161个装备／道具、2199个全部类别专长的名称、说明及已映射显示字段，另补153个职业能力。Wiki没有中文或与本版英文不同的内容，按用户授权直接补译。

本轮改动2261个条目、3458个文本字段，补充53个文件夹显示名。译名表优先；未核实名称标为暂译。原文已有的自动化疑点单列，宏参数原样保留。

项目仍为原有29个翻译文件；其余25个文件、加载脚本与发布工作流逐字节不变。HTML标签、动作字形、UUID、规则元素、数字字段与解析用内部值保持原样；仅翻译可见文字和必要的宏显示标签。

新增及改译文本完成两轮英文对照和独立中文顺读，未改旧中文不冒充本轮重新翻译。使用Babele 2.9.1原生匹配和字段映射离线验证全部5616个条目的完整转换结果；尚未进行Foundry实机测试。

完整字段差异、原英文、中文终稿、Wiki来源、原文疑点和暂译名记录在reports/localization-audit.zip内translation-sources.json的fullLocalizationUpdate中。既有复核记录保留并注明本次处理结果；其他范围的英文缺口仍在原pending-fields.csv。Wiki独有候选只列清单，不新增规则。

## 中文单位书写约定

按用户确认的中文规则圈约定，feet写作“尺”，miles写作“里”，数值沿用原文，不作公制或市制换算。“尺／英尺”和“里／英里”不因书写不同而列为规则或版本差异。原数值、范围或生效条件不同仍须单独核对。应急信标此前的单位差异记录已撤回。


## 0.3.2 模组来源说明与商用型圣洁模组修正

所有当前清单中的英文基准列明确为“模组原文”，来源为Anachronism2.4.0。73条历史字段直接回读module.zip，与Babele导出一致。模组、官方出版物和Wiki分别记录；未核官方的差异不判Wiki错译。

Holy Module (Commercial)原模组说明及自动化均为3d4；依用户核对官方2d4及明确授权，本版将商用型对邪秽目标的说明和DamageAlteration骰数同时改为2。基础1d4、商用型DC28、状态和选择器保持；战术型保留3d4/DC35，官方值待核。此项为汉化补丁中唯一的数值／规则修正例外。

修正只在加载对应资料库条目时生效。严格核对条目ID、型号、资料库、源说明和完整规则数组；不匹配时整项跳过并提示GM。不会自动改写世界和角色中的旧副本；已有商用模组需从资料库重新拖入或替换。

保持29个翻译文件和目录结构，其余28个翻译文件不变。Babele2.9.1原生映射离线验证5616条记录，仅商用型的规则值3→2发生已授权变化；尚未进行Foundry实机伤害掷骰测试。


## 0.3.3 版本兼容性声明

依据用户实测反馈，在module.json加入compatibility.verified: "14"，保留最低14.360及最高14代。移除Anachronism依赖的2.4.0版本上限，保留最低2.4.0；同时取消汉化加载脚本的精确版本锁，后续版本不会仅因版本号变化而跳过整套汉化。

29个翻译文件及现有自动化修正内容不变。商用型圣洁模组的2d4修正仍只对已核对的Anachronism2.4.0数据生效；更新版本保留其源说明和规则。新版本如改变条目ID、字段结构或规则正文，仍需对应更新译文，放宽版本限制不代表已核验未来版本的全部内容。
